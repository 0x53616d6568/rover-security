# Team workflow

This is a one-week university demo. Keep tasks small, integrate daily, and prioritize a safe working demonstration over extra features. Use the person-by-person checklists in the root README and the six focused docs under `docs/`.

Before powering motors, check wiring and ratings, test with wheels lifted, and verify the physical stop. Do not expose the rover to the public internet or commit secrets. Document actual hardware and tested behavior; label unimplemented or unverified features honestly.

# Security and safety

This repository describes a classroom prototype, not a production rover. Use it only in a controlled demonstration area and on local connectivity. Never expose its control interface to the public internet.

Do not commit passwords, tokens, private keys, or personal data. Keep a physical stop/power cut-off accessible, use low speed, and stop testing if the rover behaves unexpectedly. See [`docs/security.md`](docs/security.md) and [`docs/wiring-schematic.md`](docs/wiring-schematic.md) before testing.
